# Pre-refactor documentation archive

This directory preserves the historical documentation set that predates the
schema-11 settings, three-table room, cooperative search stages and compact
network snapshot. It is evidence only; executable code, `AGENTS.md` and the
active documents one level above are authoritative.

The original files remain at their historical paths to avoid destructive
repository changes and to preserve existing Unity `.meta` references. Archived
copies in this directory are:

- `KATAGO_MODEL_ANALYSIS.md`
- `PROJECT_KNOWLEDGE_BASE.md`
- `VRCHAT_TWO_CLIENT_CHECKLIST.md`
- `XIANGQI_PORTING_BLUEPRINT.md`

Their matching `.meta` files are retained beside each copy. The files named
`ARCHITECTURE.md`, `PLATFORM_STATUS.md` and `PROGRESS.md` in the active
directory are current documents, not archived copies.

Do not copy historical PASS/FAIL claims into a current release report without
rerunning the matching gate on the current checkout.
